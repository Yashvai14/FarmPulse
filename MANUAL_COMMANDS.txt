===============================================================
TROUBLESHOOTING
===============================================================

Port Already in Use:
- Frontend will automatically use port 3001 if 3000 is busy
- For backend, check if port 8000 is already in use

Python Not Found:
- Install Python 3.8+ from https://python.org
- Make sure "Add to PATH" is checked during installation
- Restart terminal after installation

Node.js Not Found:  
- Install Node.js 18+ from https://nodejs.org
- Restart terminal after installation

Dependencies Not Installing:
- Try: pip install --upgrade pip
- Try: npm cache clean --force
- Check internet connection

Application Not Loading:
- Wait for servers to fully start (watch terminal output)
- Backend shows "Uvicorn running on http://0.0.0.0:8000"
- Frontend shows "Ready in X.Xs" message
